# Player guide

## Installing

Every player in a world, and the dedicated server if there is one, needs the mod.

1. Install **BepInExPack for Valheim** (r2modman or Thunderstore Mod Manager do this for you).
2. Install **Greenlings**. Until it's released, use r2modman's *Import local mod* with the zip
   from `scripts/package.ps1`.
3. Start the game. The config file `BepInEx/config/greenlings.cfg` appears after the first launch.

## The short version

1. Drop **coins** near a wild greyling and keep out of sight until it's tamed. It is now a **stray**.
2. Feed it, pat it (++e++), and hang around near it until its trust reaches 100%. It turns into a
   **Greenling**.
3. Use a **coin** on it, then show it a job: take something from somewhere and put it somewhere else.
4. Build it a **Greenling Nest** and leave some food lying around.

## Controls

| Key | On a greenling |
|---|---|
| ++e++ (Pat) | Strays: affection (counts every 30 s) and they tag along briefly. Greenlings: follow / stay. While it's watching a lesson: "never mind", so it forgets its job. When it's scared: calms it. |
| ++shift+e++ | Rename (vanilla pet rename) |
| Use item (hotbar key while hovering) | **Coin**: start a lesson. **Food**: feed it. **Hammer** / **Cultivator**: hand it over (repairing / planting). |

Hover over any greenling to see its name, role, what it's doing, its traits and what ++e++ will do.
